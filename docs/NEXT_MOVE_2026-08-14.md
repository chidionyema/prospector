## The blocker, reproduced

The backfill route needs a stored dossier to re-render. Every stored PASS dossier currently
raises:

```
$ .venv/bin/python -c '<load each store/dossiers/*.pass.json via pack_manifest.dossier_from_dict, render_markdown>'
stored PASS dossiers=62 rendered_ok=0 raised=62
FIRST FAILURE: store/dossiers/08b22037fc2afc07.pass.json
  File "prospector/dossier.py", line 671, in render_markdown
    for ax, val in sc.scores.items():
AttributeError: 'types.SimpleNamespace' object has no attribute 'items'
```

Cause, not symptom: `pack_manifest._ns` (`prospector/pack_manifest.py:350-354`) descends into
*every* dict, including `score.scores` and `score.justification`, whose keys are data (axis
names), not fields. `dossier.py:309-317` (`_verdict_of`) already carries the "one reader, both
shapes" lesson for verdicts; the score maps never got it.

62 stored dossiers vs 73 stale packs — the 11 with no dossier on disk fall to the zip's
`manifest.jsonld`, which carries the checks and verdicts
(`tools/backfill_bundle_html.py:31-35`).

## The work order

1. **Make a stored dossier renderable.** One reader for value-keyed maps: either `_ns` stops
   descending into `score.scores` / `score.justification`
   (`prospector/pack_manifest.py:350-354`), or `render_markdown` reads them through a
   `_mapping()` helper at `prospector/dossier.py:671-673`, the way `_verdict_of` reads verdicts.
   Prefer the reader-side helper — it is where the shape ambiguity is already handled.
2. **Extend the backfill to regenerate `QA_Report.md`** when the stored record contradicts the
   pack's banner. This is a second, deliberate exception to the byte-identical rule; document it
   in `tools/backfill_bundle_html.py`'s docstring next to the first (`:20-28`), same narrowness.
   Content-compared, so re-running is a no-op.
3. **Re-upload and re-verify from R2, not disk.** `tools/preview_packs.py --from r2` is the only
   source that proves what a buyer receives; the probe's disk mode is the floor, not the proof.
4. **Keep it from returning.** `scripts/pack_banner_probe.py` (currently untracked — commit it)
   exits 1 while any live pack carries the retired sentence. Wire it into the same gate as
   `scripts/site_spec_probe.py`.
