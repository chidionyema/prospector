# Mumchimp build bundle

START HERE
- `components.html`  — the component sheet. 15 components, every state. Open in a browser.
- `mumchimp.css`     — the production stylesheet. Ship as-is. The agent writes no CSS.
- `MASTER-BRIEF.md`  — engineering spec, data layer, build order, acceptance.

ALSO
- `AGENT-FIX-PROMPT.md`        — corrective prompt for the current drifted build
- `PLAIN-ENGLISH-AND-PARITY.md`— banned words + the parity test method
- `POLISH-LAYER.md`            — perceived speed, touch feel, forms, print
- `mockups/`                   — 12 reference pages, index.html is the landing page

RULE: copy markup and class names from components.html. Import mumchimp.css unchanged.
If a style you need isn't in it, stop and ask.
