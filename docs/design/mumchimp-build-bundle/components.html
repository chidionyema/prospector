Every component, every state.

Fifteen components rendered from mumchimp.css — the same stylesheet the site ships. Each one shows its default, its awkward real content, and its mobile behaviour. Approve these once and the pages cannot be wrong, because a page is only an assembly of these parts.

For the developer: copy the markup and class names from this file exactly. Do not write CSS. If a style you need is not in mumchimp.css, stop and ask.

Component 03

Buttons and links

One button style. Secondary is the ghost button or a text link. There is no third.

All variantsprimary · ghost · small · text link

Browse the packs Read the kill log Buy this pack Download Read a full pack free — no email needed

Never disable a button. Let it be pressed and say what is wrong.

No full stop at the end of a link or a button, ever.

Pressed state is required: scale(.985) on :active. A control that does not acknowledge a press feels like a picture of a control.

Hover effects sit inside @media (hover:hover) so they do not stick after a tap on mobile.

The description is never truncated by the server. It arrives whole and is clamped to two lines in CSS. Every current mid-sentence cut is a data-layer bug.
